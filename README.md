The project includes:
Hopfield Network – associative memory to store and recall binary patterns.
Perceptron – single‑layer linear classifier (baseline).
Backpropagation Multi‑Layer Network (MLP) – trainable network for digit classification.
JavaFX OCR Demo – an interactive widget where users draw hand‑written digits in a 10×10 pixel grid, which are then classified by the network , Hopfield Network & MLP
